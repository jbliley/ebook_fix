# ebook_fix
An automated tool that will be able to detect and fix both common and uncommon issues with eBook files.

The ultimate goal of this project is to allow any type of eBook file to be fixed without the need of running it through AI, as they are often too large for free usage. This idea is stemming from the many free eBook files online that are poorly converted from early PDF files, or those that were printed directly from HTML files from 20+ years ago.

Planned Software Capabilities
<ul>Read contents and structure of eBook file</ul>
<ul>Display detected contents in a detailed summary</ul>
<ul>Fix issues based on the detected discrepancies</ul>

As this project is in its infancy, I am only starting to add Python modules that will read and save the file structure. At first this will consist of only a CLI, but I'm hoping a GUI will eventually be created.
