ebook_fix

Analyze and repair a single EPUB file. A MOBI/AZW/AZW3/PRC, FB2 or HTML book is converted to EPUB first.

Browse for a book on your computer. A MOBI, FB2 or HTML file is converted to a new EPUB saved next to the original (the original isn't touched), and that EPUB is what opens here. This runs entirely on your own computer — nothing is uploaded anywhere outside this program, and opening a file this way (rather than dragging one in) is what lets it correctly detect Calibre and save fixes back to the right folder.

Fix a Folder of Books

Fixes every book in a folder, one after another, the same way the Fix This Book button would with nothing changed on the other tabs. A fixed copy is saved next to each book unless you choose to replace the originals. A book with nothing wrong is left alone, and a book that cannot be fixed never stops the rest. Anything that needs a decision is marked so you can open that book and look.

The untouched original is kept next to it as name_original, so nothing is lost.

Leave this off for a folder that may hold web pages that are not books.
